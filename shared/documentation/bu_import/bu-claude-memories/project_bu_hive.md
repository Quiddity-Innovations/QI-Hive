Restarts no-op because the control script's `:isrunning` port check sees the zombie socket and assumes "already running," then just reopens the browser to the **cached dead tab**. **Fix:** find the live `multiprocessing.spawn ... --multiprocessing-fork` python child via `Get-CimInstance Win32_Process`, `taskkill /F /PID <child>` to release 8730, then start fresh from `C:\AI\BU Hive` (`.venv\Scripts\python.exe app\main.py`, single process). Browser needs **Ctrl+F5** — a normal refresh of the old tab kept showing BU Brain.
